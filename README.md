1. Nama & Tujuan Aplikasi <br>
   Nama Aplikasi:
   # SIPBAN (Sistem Informasi Pendataan Pasca Banjir)
   Tujuan: <br>
   Platform berbasis web untuk memudahkan relawan/petugas lapangan (Surveyor) mendata kerusakan rumah warga yang terdampak banjir, lengkap dengan fitur unggah foto bukti kerusakan, serta dasbor Admin untuk rekapitulasi dan verifikasi data.
